## 简介
本文件面向回测引擎的使用者与开发者，系统化阐述该项目的回测能力与实现方式。内容覆盖：
- 数据加载、信号生成、订单执行与绩效评估四大模块
- 历史数据处理流程、滑点模拟、手续费计算与资金管理
- **新增**：仓位乘数上限支持与波动率覆盖层集成
- 回测性能优化（并行、内存管理、缓存）
- 结果分析指标（夏普比率、最大回撤、胜率等）
- 回测脚本编写指南与批量回测功能

## 项目结构
回测相关代码主要分布在以下层次：
- API 层：提供 HTTP 接口与请求/响应模型定义
- 服务层：编排回测任务、协调引擎与存储
- 引擎层：股票与加密货币两类回测引擎，封装交易循环与绩效统计
- **新增**：波动率覆盖层：根据EWMA波动预测动态调整仓位限制
- 仓储层：持久化回测结果与查询
- 工具与数据层：为回测提供数据加载、处理与辅助工具

## 核心组件
- 回测引擎（股票/加密）：负责按时间步推进历史数据，调用策略产生信号，执行订单并更新资金与持仓，记录成交与净值曲线，最终输出绩效指标。
- 服务层：接收 API 请求，组装参数，调度引擎运行，支持异步与批量任务，统一异常与日志。
- **新增**：波动率覆盖层：基于EWMA波动预测动态调整仓位乘数上限，在高风险市场环境下自动缩减仓位规模。
- 仓储层：将回测结果（订单流水、净值、指标）持久化，并提供查询接口。
- Agent 工具：在对话式 Agent 中暴露回测能力，便于通过自然语言触发回测。
- 数据与工具：提供标的索引、数据清洗与常用计算函数，支撑回测的数据准备与后处理。

## 详细组件分析

### 股票回测引擎
- 职责
  - 加载标的历史数据与基准
  - 按日频推进，计算技术指标与信号
  - 根据信号生成订单，应用滑点与手续费
  - 维护账户资金、持仓与成交明细
  - 计算净值曲线与绩效指标（如夏普比率、最大回撤、胜率等）
- 关键流程
  - 初始化：读取配置（初始资金、滑点、费率、风控阈值）
  - 数据准备：对齐时间轴、填充缺失值、标准化字段
  - 信号生成：调用策略或外部信号源
  - 订单执行：撮合逻辑、成交确认、费用扣除
  - 绩效统计：滚动窗口收益、波动率、回撤、胜率统计
- 性能要点
  - 向量化计算优先，减少 Python 循环
  - 内存复用与惰性加载，避免重复 IO
  - 可选并行：多标的并行回测

### 波动率覆盖层（新增）
- 职责
  - 基于EWMA波动预测模型，动态调整仓位乘数上限
  - 在市场波动率升高时自动缩减仓位规模，降低风险暴露
  - 不改变交易方向，仅调整仓位大小
- 工作机制
  - 输入：技术上下文中的波动率预测（forecast_sigma_pct、regime等）
  - 处理：根据波动状态（normal/elevated/extreme）应用不同的仓位限制
  - 输出：调整后的position_multiplier_cap和risk_overlay信息
- 风险控制
  - 取波动率覆盖层建议值与现有仓位限制的较小值
  - 确保不会因风险覆盖放大仓位规模
  - 提供详细的覆盖层应用记录和说明

```mermaid
flowchart TD
Input["技术上下文<br/>波动率预测"] --> Check["检查数据质量<br/>和可用状态"]
Check --> |可用| Process["应用EWMA覆盖层"]
Check --> |不可用| Skip["跳过覆盖层"]
Process --> Calculate["计算仓位乘数上限<br/>min(源值, 现有值)"]
Calculate --> Apply["应用到交易计划"]
Apply --> Output["返回调整后的计划<br/>包含risk_overlay详情"]
Skip --> Output
```

### 仓位乘数上限支持（新增）
- 核心功能
  - **仓位乘数上限验证**：在回测引擎中验证和执行由波动率覆盖层生成的仓位限制
  - **风险预算缩放**：根据仓位乘数上限按比例缩减风险预算和名义仓位
  - **数量计算调整**：基于缩放后的风险预算重新计算交易数量
- 实现机制
  - `_position_sizing`方法接受`position_multiplier_cap`参数
  - 将乘数应用于风险预算和最大名义仓位计算
  - 保持原有仓位计算方法不变，仅缩放输入参数
- 效果验证
  - 当设置`position_multiplier_cap=0.25`时，风险预算、名义仓位和数量均缩减至原值的25%
  - 确保在高波动环境下自动降低风险暴露

```mermaid
flowchart TD
Plan["原始交易计划"] --> Overlay["波动率覆盖层<br/>生成仓位限制"]
Overlay --> Validation["回测引擎验证<br/>position_multiplier_cap"]
Validation --> Sizing["_position_sizing<br/>应用乘数缩放"]
Sizing --> RiskBudget["风险预算 = 原始 × 乘数"]
Sizing --> Notional["名义仓位 = 原始 × 乘数"]
RiskBudget --> Quantity["数量 = min(风险缩放数量, 名义限制)"]
Notional --> Quantity
Quantity --> Result["调整后仓位"]
```
