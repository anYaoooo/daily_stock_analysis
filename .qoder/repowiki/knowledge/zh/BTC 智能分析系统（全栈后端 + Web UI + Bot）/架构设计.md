项目采用分层 + 多入口的单体仓库结构：
- 入口层：`main.py` 是 CLI/调度器主程序，解析 `--serve/--webui/--schedule/--backtest` 等参数并驱动 `src.core.pipeline.StockAnalysisPipeline`；`server.py` 通过 uvicorn 启动 FastAPI 应用；`api/app.py` 用 `create_app()` 工厂组装 CORS、认证中间件、路由与健康检查，并托管 `static/` 下的 Vite 构建产物。
- API 层：`api/v1/endpoints/` 按业务域拆分（agent/alerts/analysis/auth/backtest/crypto_trading/portfolio/stocks/system_config/usage），配合 `api/v1/schemas/` Pydantic 模型统一入参出参，`api/middlewares/` 提供 auth 与全局错误处理。
- 核心领域层（`src/`）：`core/` 包含 pipeline、market_review、trading_calendar、btc_only 模式开关与回测引擎；`agent/` 实现多 Agent（decision/intel/portfolio/risk/technical）+ skills + strategies + tools 的可插拔编排；`services/` 为各业务域的服务聚合（alert、portfolio、history、backtest、crypto 交易等）；`repositories/` 封装 SQLite/文件持久化；`notification_sender/` 抽象邮件、飞书、Discord、Telegram、Pushover 等多种通知渠道；`data_provider/` 统一接入 akshare/tushare/yfinance/longbridge/crypto_ws 等数据源。
- 前端层：`apps/dsa-web/` 是独立 Vite + React + TypeScript SPA，`apps/dsa-desktop/` 基于 Electron 打包桌面应用；生产模式下由 FastAPI 直接 serve `static/` 静态资源。
- 配置与生命周期：`src/config.py` 单例管理 `.env` 环境变量与类型安全 Config 对象；`src/logging_config.py` 集中日志；`docker/` 提供 Dockerfile 与 entrypoint。
依赖方向自顶向下：API → services → repositories/data_provider/agent/core → 外部 LLM/数据源，反向无依赖。
