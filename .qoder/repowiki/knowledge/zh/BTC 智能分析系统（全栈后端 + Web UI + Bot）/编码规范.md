- API 路由按业务域拆分为 `api/v1/endpoints/*.py`，每个模块对应一个 Pydantic schema 文件于 `api/v1/schemas/`，通过 `api/v1/router.py` 统一注册到 `/api/v1` 前缀。
- 配置统一通过 `src.config.Config` 单例读取，所有环境变量在 `src/config.py` 中以带默认值与范围校验的 `parse_env_*` 函数解析，避免散落的 `os.getenv`。
- 外部可插拔组件（数据源 fetcher、通知 sender、Agent、skill、strategy）均通过基类 + 注册表模式实现，新增实现只需继承基类并注册即可被自动发现。
- 服务层以 `*_service.py` 命名并按职责单一拆分（如 `alert_service`、`portfolio_service`、`backtest_service`），由上层 pipeline 或 API endpoint 组合调用。
- 日志统一经 `src.logging_config.setup_logging` 初始化，CLI 路径先 stderr 后降级为文件日志，API 路径额外排除 uvicorn/fastapi 噪音 logger。
- 对外暴露的 HTTP 响应与内部数据契约均使用 Pydantic model 定义（`schemas/` 与 `v1/schemas/`），保证 OpenAPI 文档自动生成与运行时校验。
