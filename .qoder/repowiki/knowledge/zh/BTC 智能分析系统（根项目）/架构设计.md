根目录提供三个进程级入口：main.py 是调度主程序，负责解析命令行参数、加载 .env 与代理配置、初始化日志，并协调 StockAnalysisPipeline 执行 BTC 日线/小时线分析、大盘复盘、回测与通知；server.py 与 webui.py 均通过 uvicorn 启动同一 FastAPI 应用（api.app:app），前者作为 API 后端独立运行，后者作为 WebUI 前端托管入口。所有子模块通过 src.* 包暴露接口，由 main.py 按需懒加载以避免冷启动开销；Docker 镜像（docker_deploy）复用同一入口脚本，支持 --serve-only 与定时任务双模式。CI/CD（github_ci）、测试（tests）、文档（docs）与构建脚本（scripts）围绕同一 pyproject.toml 与 requirements.txt 依赖集组织，形成统一的开发-构建-部署流水线。
