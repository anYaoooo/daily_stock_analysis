该模块为纯模板层，由一个共享宏文件 `_macros.j2` 和三个独立报告模板组成：
- `_macros.j2`：定义 `market_snapshot` 宏，被 `report_markdown.j2` 通过 `{% from '_macros.j2' import market_snapshot with context %}` 引入复用。
- `report_brief.j2`：极简单行简报，仅遍历 `enriched` 列表输出每只股票的信号、评分与一句话结论。
- `report_markdown.j2`：完整 Markdown 报告，按 `enriched` 逐项展开 `intelligence`、`core_conclusion`、`data_perspective`、`phase_decision`、`battle_plan` 等 dashboard 子结构，并支持 `summary_only` 开关。
- `report_wechat.j2`：针对微信阅读优化的紧凑版，对长文本做截断（`[:50]`/`[:80]`），使用 emoji 与短横线分隔符提升可读性。
三个模板共享相同的上下文变量约定（`results`、`enriched`、`labels`、`report_date`、`report_timestamp`、`show_llm_model`、`models_used`、`history_by_code` 等），依赖方向单向：模板 → `_macros.j2`，模板之间互不引用。
