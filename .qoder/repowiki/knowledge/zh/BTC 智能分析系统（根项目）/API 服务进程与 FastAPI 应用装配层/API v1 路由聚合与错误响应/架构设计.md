该模块由三个文件组成：`router.py` 作为 v1 版本的入口，使用 FastAPI 的 `APIRouter` 创建主路由并通过 `include_router` 将 `agent、alerts、analysis、auth、backtest、decision_signals、crypto_trading、health、history、portfolio、stocks、system_config、usage` 等子模块路由按 `/auth`、`/agent`、`/analysis` 等路径前缀和对应 `tags` 注册；`errors.py` 提供统一的错误响应构造函数（`error_body`、`api_error`、`error_json_response`），基于 `HTTPException` 和 `JSONResponse` 生成包含 `error`、`message`、可选 `detail` 字段的标准化 JSON 结构；`__init__.py` 仅做导出，将 `router` 重命名为 `api_v1_router` 供上层 `api.app` 挂载，注释明确说明前缀在 `api.app` 层添加以避免新版 FastAPI 误判空路径。依赖方向单向向下：router → endpoints.* → errors，无反向依赖。
