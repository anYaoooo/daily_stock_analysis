- 应用装配统一通过工厂函数 `create_app(static_dir)` 返回 FastAPI 实例，而非直接全局实例化，便于测试与多环境复用。
- 依赖注入采用 FastAPI 的 `Depends` + 生成器模式（如 `get_db` 中 `try/finally` 确保 Session 关闭）。
- 请求级共享状态通过 `request.app.state` 存取（如 `system_config_service`），在 `app_lifespan` 中初始化并在 finally 中清理。
- 对外暴露的端点统一使用装饰器链式声明（如 `@app.get` + `@app.api_route`），并附带 `response_model`、`tags`、`summary`、`description` 等 OpenAPI 元数据。
- 静态资源访问前通过 `_resolve_asset_path` 做路径白名单校验（拒绝 `..`、空字节、反斜杠、盘符冒号），防止目录穿越攻击。
