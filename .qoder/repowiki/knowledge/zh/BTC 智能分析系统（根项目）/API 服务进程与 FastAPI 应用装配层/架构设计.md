- `server.py` 是 uvicorn 的进程入口：加载配置、初始化日志后从 `api.app` 导入已构建好的 `app` 实例。
- `api/app.py` 通过 `create_app()` 工厂函数组装应用：注册 CORS、调用 `add_auth_middleware` 注入认证中间件、挂载 `api.v1.api_v1_router`（前缀 `/api/v1`）、注册全局错误处理器，并提供根路径 `/` 的前端 SPA 回退与 `/health` 健康检查。
- 应用生命周期由 `app_lifespan` 管理，将 `SystemConfigService` 等共享服务挂到 `app.state`，并在关闭时清理后台任务。
- 中间件与路由解耦：认证逻辑在 `api/middlewares/auth.py`，统一错误响应在 `api/middlewares/error_handler.py`，业务路由按领域拆分在 `api/v1/endpoints/` 下，由 `api/v1/router.py` 聚合。
- 静态资源托管采用安全校验的自定义 `/assets/{path}` 处理器与 SPA 回退，避免目录穿越并保证缺失资源返回明确的 text/plain 404。
