- 配置项统一在 src/config.py 的 Config dataclass 中声明默认值，并通过 parse_env_* 函数从环境变量解析并做范围校验。
- 数据库模型统一继承 SQLAlchemy declarative_base，使用 __table_args__ 声明唯一约束与索引，并通过 CURRENT_SCHEMA_VERSION 常量配合 schema_migrations 表进行迁移。
- 定时任务通过 scheduler.add_background_task 注册，间隔最小 5 秒，异常在 daemon 线程内捕获并记录日志。
- 对外 API 返回类型集中在 schemas/* 中用 Pydantic/TypedDict 定义，services 层仅操作这些契约对象。
- 通知发送器均实现 notification_contracts 定义的统一接口，通过 notification_routing 按 channel 名称分发。
