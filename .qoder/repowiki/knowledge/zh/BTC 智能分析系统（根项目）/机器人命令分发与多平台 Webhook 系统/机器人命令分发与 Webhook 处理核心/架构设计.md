模块由四层构成：
- 数据模型层（models.py）：通过 dataclass 定义 BotMessage、BotResponse、WebhookResponse 和 ChatType/Platform 枚举，屏蔽各平台差异。
- 命令分发层（dispatcher.py）：CommandDispatcher 负责命令注册/别名/权限校验/频率限制（RateLimiter），提供同步 dispatch() 与异步 dispatch_async() 双入口；内置两层自然语言路由——正则预过滤 + LLM 意图解析（调用 src.agent.llm_adapter.LLMToolAdapter），将非命令消息路由到 /chat 或 /ask。
- Webhook 适配层（handler.py）：handle_webhook/handle_webhook_async 作为统一入口，按 platform_name 从 ALL_PLATFORMS 缓存获取平台适配器，完成 JSON 解析、延迟 ACK 与响应格式化。
- 包导出（__init__.py）：仅暴露 BotMessage/BotResponse/ChatType/WebhookResponse/CommandDispatcher/get_dispatcher，隐藏内部实现。
依赖方向单向向下：handler → dispatcher → models，并通过 from ... import 在函数体内惰性加载 src.config、src.agent.*、bot.commands.ALL_COMMANDS 等外部模块，避免循环导入。全局单例 get_dispatcher() 在首次调用时自动注册 bot.commands.ALL_COMMANDS 中所有命令。
