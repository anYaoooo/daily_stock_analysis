多入口运行方式：`python main.py --serve-only` 仅启动 API，`python main.py --serve` 同时启动 API 与分析任务，`python main.py --webui` 启动 Web UI，`python main.py --schedule` 启用北京时间 08:00 日线分析与每小时 05 分小时线监控；CLI 支持 `--dry-run`、`--stocks BTC`、`--backtest`、`--workers`、`--no-context-snapshot` 等参数；环境变量通过 `.env` 或 `ENV_FILE` 注入，代理通过 `USE_PROXY`/`PROXY_HOST`/`PROXY_PORT` 控制；Docker 部署使用 `docker/Dockerfile` + `entrypoint.sh`。
