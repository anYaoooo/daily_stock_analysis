- 配置集中通过 `src/config.py` 的 dataclass 单例加载 `.env`，并提供 `parse_env_bool/int/float` 等带默认值与边界校验的解析函数。
- API 端点按领域拆分到 `api/v1/endpoints/`，每个文件对应一个业务域（如 `analysis.py`、`portfolio.py`），请求/响应模型统一放在同目录 `schemas/` 下的 Pydantic 类中。
- 外部依赖（pipeline、notifier、analyzer 等）采用延迟 import 模式，避免在模块导入阶段触发重初始化或网络 I/O。
- 通知发送一律通过 `NotificationService.send_with_results` 并附带 `route_type`、`severity`、`dedup_key`、`cooldown_key`，保证去抖与可观测性。
- 长耗时任务（大盘复盘、BTC 波动监控）通过 `market_review_lock` 或线程锁保护，防止并发重复执行。
- 日志统一经 `src/logging_config.setup_logging` 初始化，区分 `stock_analysis`、`api_server` 等前缀，并在文件写入失败时降级为控制台输出。
