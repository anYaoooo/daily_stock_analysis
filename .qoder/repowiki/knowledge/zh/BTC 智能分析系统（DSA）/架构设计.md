项目采用多进程/多入口的单体仓库架构，按职责划分为清晰子包：
- 入口层：`main.py` 是 CLI/调度器主程序，解析 `--serve/--webui/--schedule/--backtest` 等参数，通过 `src.core.pipeline.StockAnalysisPipeline` 编排 BTC 分析流程；`server.py` 仅启动 uvicorn + `api.app`；`webui.py` 负责前端资源准备。
- API 层：`api/app.py` 用 FastAPI 工厂函数创建应用，注册 CORS、认证中间件、错误处理器，并通过 `api/v1/router.py` 挂载 `/api/v1/*` 路由，各业务端点位于 `endpoints/`，Pydantic 请求/响应模型集中在 `schemas/`。
- 核心引擎：`src/core/pipeline.py` 定义 `StockAnalysisPipeline`，串联数据获取、LLM 分析、通知、回测；`src/core/market_review*` 实现大盘复盘与锁机制；`src/core/backtest_engine.py` / `crypto_backtest_engine.py` 分别处理股票与 BTC 回测。
- Agent 框架：`src/agent/` 实现多 Agent 协作（`agents/base_agent.py` + `decision/intel/portfolio/risk/technical`），通过 `orchestrator.py` 编排、`executor.py` 执行、`llm_adapter.py` 对接 LiteLLM；`skills/`、`strategies/`、`tools/` 以插件形式扩展能力。
- 数据层：`data_provider/` 统一抽象各类行情源（akshare/yfinance/tushare/crypto_* 等），`src/repositories/` 封装 SQLite 读写，`src/services/` 聚合业务服务（portfolio/alert/backtest/notification 等）。
- 通知与 Bot：`src/notification_sender/` 实现邮件/飞书/Discord/Pushover 等多通道；`bot/` 提供钉钉/飞书/Discord 等平台命令式机器人。
- 前端：`apps/dsa-web` 为 Vite+React SPA，构建产物由 `static/` 托管；`apps/dsa-desktop` 基于 Electron 打包桌面版。
依赖方向自上而下：入口 → API → services → repositories/data_provider → LLM/通知；Agent 框架横向贯穿 services 调用。
