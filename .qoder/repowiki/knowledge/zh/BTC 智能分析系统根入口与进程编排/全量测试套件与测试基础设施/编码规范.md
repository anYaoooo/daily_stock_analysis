- 每个被测模块对应一个 `test_*.py` 文件，文件名与被测功能域一一对应（如 `test_agent_executor.py`、`test_api_health.py`）。
- 测试类统一继承 `unittest.TestCase` 并使用 `setUpClass`/`tearDownClass` 管理共享资源（临时目录、mock patcher）。
- 需要 LLM 能力的测试通过 `try/except ModuleNotFoundError` 捕获缺失的 litellm 依赖，并在 `sys.modules` 中注入 `MagicMock()` 或调用 `ensure_litellm_stub()` 保持可运行。
- API 端点测试通过 `fastapi.testclient.TestClient(create_app(...))` 构造应用实例，并用 `tempfile.TemporaryDirectory()` 隔离静态目录。
- 异步/多线程相关的测试在 `conftest.py` 中通过 monkeypatch 修复 AnyIO 与 asyncio 的线程交互问题，而非在每个测试中重复处理。
