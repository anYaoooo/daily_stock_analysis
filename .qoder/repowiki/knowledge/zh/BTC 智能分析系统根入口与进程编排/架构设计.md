根目录承担进程装配与环境引导职责：main.py 解析 argparse 参数并懒加载 src.core.pipeline.StockAnalysisPipeline，按 --schedule/--serve/--webui 等标志调度日线/小时线分析、大盘复盘、回测与通知；server.py 与 webui.py 均通过 uvicorn 启动同一 FastAPI 应用（api.app:app），前者作为独立 API 后端，后者托管 WebUI 前端静态资源。所有业务子模块通过 src.* 命名空间暴露接口，由入口脚本在首次使用时延迟导入以避免冷启动开销；Docker 镜像（docker_deploy）复用相同入口脚本并以 gosu 修复权限后支持 --serve-only 与定时任务双模式。CI/CD（github_ci）、测试（tests）、文档（docs）与构建脚本（scripts）围绕同一 pyproject.toml 与 requirements.txt 依赖集组织，形成统一的开发-构建-部署流水线。
