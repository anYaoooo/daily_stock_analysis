- 每个 Python 脚本以 shebang 开头并通过 argparse 暴露命令行参数，主函数统一通过 sys.exit(main()) 返回退出码。
- 脚本通过 Path(__file__).resolve().parent.parent 定位仓库根目录，并将根目录插入 sys.path 后再导入 src/、data_provider/ 等业务模块。
- Shell 脚本统一使用 set -euo pipefail 并在顶部定义 SCRIPT_DIR/REPO_ROOT，子命令失败时直接中止。
- PowerShell 脚本设置 $ErrorActionPreference = 'Stop'，对外部命令使用 -File 调用并以显式 exit 0/1 表达成功/失败。
- 数据类脚本输出固定前缀日志（如 [check_static_assets]、[refresh_stock_index]、[ai-assets]），便于 CI 过滤与定位问题。
- 对可选依赖采用 try/except ImportError 包裹并在缺失时给出安装提示，保证脚本在无依赖环境下仍可优雅失败。
