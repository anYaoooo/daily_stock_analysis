该模块为纯配置型目录，按 GitHub 约定组织：
- `workflows/`、`scripts/`、`ISSUE_TEMPLATE/`、`instructions/` 子目录用于存放 GitHub Actions 工作流、CI 脚本、Issue 模板和路径专属指令（当前快照中这些目录为空或仅含占位）。
- 顶层文件承担不同职责：`requirements-ci.txt` 通过 `-r ../requirements.txt` 复用项目根依赖并追加 flake8、pytest 作为后端 CI 工具；`release.yml` 使用 GitHub Release Changelog 生成器，按标签分类（enhancement、ai、bug、data-source、notification、configuration、testing、ci/cd、documentation、*）自动生成变更日志，并排除 dependabot 与 github-actions[bot] 作者。
- `PULL_REQUEST_TEMPLATE.md` 提供中英双语 PR 模板，强制要求填写验证命令、兼容性风险、回滚方案以及 EXTRACT_PROMPT 变更。
- `copilot-instructions.md` 指向根目录 `AGENTS.md` 作为唯一权威源，定义目录边界、提交/PR 命名规范、验证流程与 AI 资产治理规则。
- `CODEOWNERS` 将所有文件默认归属 `@ZhuLinsen`，`FUNDING.yml` 指向自定义赞助链接。
依赖方向单向向外：本模块不引入任何可执行逻辑，仅被 GitHub 平台在 PR/Issue/Release/Actions 触发时读取。
