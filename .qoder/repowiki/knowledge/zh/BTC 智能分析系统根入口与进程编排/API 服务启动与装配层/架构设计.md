- `server.py` 是 uvicorn 的进程入口：先调用 `src.config.setup_env` 与 `src.logging_config.setup_logging` 完成环境与日志初始化，再从 `api.app` 导入已构建好的 `app` 实例供 uvicorn 直接运行。
- `api/app.py` 通过 `create_app()` 工厂函数完成装配：注册 CORS、调用 `add_auth_middleware` 注入认证中间件、挂载 `api.v1.api_v1_router`（前缀 `/api/v1`）、注册全局错误处理器，并提供根路径 `/` 的 SPA 回退与 `/health` 健康检查；应用生命周期由 `app_lifespan` 管理，将共享服务挂到 `app.state` 并在关闭时清理后台任务。
- 横切关注点解耦：认证逻辑位于 `api/middlewares/auth.py`，统一 HTTP 错误响应位于 `api/middlewares/error_handler.py`，业务路由按领域拆分在 `api/v1/endpoints/` 下并由 `api/v1/router.py` 聚合挂载。
- 静态资源通过自定义 `/assets/{path}` 处理器与安全校验实现目录穿越防护，缺失资源返回明确的 text/plain 404。
