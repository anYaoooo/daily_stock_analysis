本模块由三个文件构成应用装配层：
- `app.py` 是核心入口，通过 `create_app(static_dir)` 工厂函数构建 FastAPI 实例，使用 `@asynccontextmanager` 定义的 `app_lifespan` 管理 `SystemConfigService` 生命周期；集中注册 CORS、认证中间件（`add_auth_middleware`）、错误处理器（`add_error_handlers`）和 `/api/v1` 路由；根据 `static_dir/index.html` 是否存在动态切换 SPA 静态托管或返回引导页，并通过正则校验前端资源一致性。
- `deps.py` 暴露 FastAPI 依赖函数：`get_db`（基于 `DatabaseManager.get_instance()` 的 SQLAlchemy Session 生成器）、`get_config_dep`、`get_database_manager`、`get_system_config_service`（从 `request.app.state` 读取共享服务），供路由层通过 `Depends(...)` 注入。
- `__init__.py` 仅导出模块版本 `__version__ = "1.0.0"`。
依赖方向单向向外：本模块依赖 `src.storage`、`src.config`、`src.auth`、`src.services.system_config_service` 以及 `api.v1`、`api.middlewares.*`，不反向被这些模块依赖，形成清晰的装配边界。
