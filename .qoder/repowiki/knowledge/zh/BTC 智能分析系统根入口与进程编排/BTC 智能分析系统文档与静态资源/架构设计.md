本模块为纯静态文档与资源目录，无可执行代码，按用途划分为：根级 Markdown 文档（README/INDEX/DEPLOY/FAQ/CONTRIBUTING 等中英文对照），其中 INDEX.md 作为统一入口按「快速开始 / 配置 / 使用专题 / 部署与打包 / 参考与开发 / 多语言」场景组织导航；`architecture/api_spec.json` 是 FastAPI 自动导出的 OpenAPI 3.1.0 规范，集中定义 Health/Analysis/History/SystemConfig/DecisionSignals 五大标签的 REST 接口与 SSE 流，作为前后端契约的唯一权威来源；`assets/` 存放通用图片/GIF/支付渠道截图，`assets/dsa_vi/` 专放应用图标源文件（PSD/AI）与多分辨率 iconset；`bot/` 以「Markdown 步骤说明 + 配套截图」形式提供飞书/钉钉/Discord 等平台 Bot 配置图文；`docker/zeabur-deployment.md` 与 `examples/litellm_config.example.yaml` 分别提供云平台部署与 LiteLLM 多渠道示例。文档之间通过相对路径互相引用，不依赖外部构建工具。
