本模块由三个文件组成完整的容器化方案：
- `Dockerfile` 采用两阶段构建：`node:20-slim` 作为 `web-builder` 前端打包生成静态资源，再复制到 `python:3.11-slim-bookworm` 运行时镜像中；应用以非 root 用户 `dsa`(UID/GID 1000) 运行，暴露 8000 端口并通过 HEALTHCHECK 探测 `/api/health` 或 `/health`。
- `docker-compose.yml` 通过 YAML anchor `x-common` 复用构建上下文、卷挂载、环境变量和日志轮转策略，定义两个服务：`analyzer`（默认定时模式）和 `server`（FastAPI 服务模式），数据持久化到宿主机 `../data`、`../logs`、`../reports`、`../strategies` 及 Longbridge OAuth token 缓存目录。
- `entrypoint.sh` 在容器启动时以 root 身份检查并修复 bind mount 目录的属主/权限（针对 SQLite WAL/SHM 文件及 `/home/dsa/.longbridge`），然后使用 `gosu` 降权执行实际命令。
依赖方向：compose → Dockerfile → entrypoint.sh，entrypoint 仅依赖系统工具（gosu、find、chmod），不依赖 Python 代码。
